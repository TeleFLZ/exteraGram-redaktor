# 🧩 exteraGram Plugins

Репозиторий с пользовательскими плагинами для Telegram-клиента **exteraGram**.

## 🚀 Доступные плагины

### 1. Text Enhancer (`plugins/text_enhancer.py`)
Плагин для быстрого форматирования текста: исправляет двойные пробелы, знаки препинания и заглавные буквы.

**Команды:**
* `.улучшить` (в ответ на сообщение) — исправляет текст выбранного сообщения.
* `.draft <текст>` — отправляет сообщение с прикрепленной inline-кнопкой «Улучшить».

---

## 📥 Как установить в exteraGram

1. Скачайте нужный `.py` файл из папки `plugins/`.
2. Отправьте его себе в чат **Избранное (Saved Messages)** в Telegram.
3. Нажмите на файл и выберите **Установите плагин**.
